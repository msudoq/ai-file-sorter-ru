# Краткое руководство

AI File Sorter помогает упорядочивать файлы с удобным процессом предварительной проверки и дополнительным автоматическим подтверждением действий, которым вы доверяете.

Искусственный интеллект выполняет анализ и предлагает категории, подкатегории и имена файлов. Приложение не изменяет ваши файлы без спроса: перемещение или переименование происходит только после того, как вы подтвердите предложенные изменения, либо автоматически, если включены соответствующие параметры автоподтверждения.

## Безопасный первый запуск

Если вы запускаете AI File Sorter впервые, начните с небольшой тестовой папки, прежде чем обрабатывать крупные архивы или целые диски.

Примеры подходящих папок для первого знакомства:

- копия 20–50 файлов из папки `Загрузки` (Downloads)
- небольшая папка со скриншотами или фотографиями
- временная папка с несколькими PDF-файлами или документами

Это позволит легко проверить работу приложения. При использовании локальных моделей ваши файлы остаются исключительно на вашем компьютере, а нейросеть лишь формирует рекомендации. Оставьте автоподтверждение выключенным при первом запуске, чтобы ни один файл не перемещался до вашего одобрения.

## 1. Выберите папку

Используйте кнопку **Обзор…** или панель **Проводник файлов**, чтобы указать папку для сортировки.

Типичные примеры:

- папка `Загрузки`
- папка для разбора файлов на рабочем столе
- папка на внешнем диске
- сетевая папка или облачное хранилище
- архив проекта

## 2. Настройте действия приложения

С помощью главных переключателей укажите, что именно требуется выполнить:

- категоризировать файлы по папкам
- анализировать содержимое изображений
- анализировать содержимое документов
- предлагать новые осмысленные имена для поддерживаемых файлов

Если вам требуется только переименование без перемещения по папкам, включите соответствующий режим «только переименование».

## 3. Выберите стиль категоризации

Выберите режим, наиболее подходящий под ваши задачи:

- **Детализировано** — для повседневного использования и более точной группировки
- **Единообразно** — для строгого единообразия категорий сходных файлов

Также можно включить белые списки категорий, если требуется ограничить сортировку фиксированным набором названий.

## 4. Запустите анализ

Нажмите кнопку **Анализировать папку**.

Приложение просканирует указанную директорию, соберет необходимые метаданные и подготовит список рекомендаций.

## 5. Проверьте изменения перед применением

В окне проверки вы сможете просмотреть:

- предложенные категории
- подкатегории (при включении)
- варианты переименования для поддерживаемых файлов
- итоговые пути назначения
- предпросмотр файлов

Вы можете скорректировать любое предложение или отклонить его перед подтверждением.

## 6. Примените изменения

После нажатия кнопки подтверждения приложение автоматически создаст нужные папки и выполнит перемещение или переименование файлов. Если было включено автоподтверждение, подходящие файлы обработаются без задержки в диалоге проверки.

## 7. Отмена последнего запуска

Если после применения изменений вы захотите вернуть всё назад, воспользуйтесь пунктом меню **Правка -> Отменить последний запуск**.

Функция отмены ориентирована на самый последний подтверждённый запуск. На основе сохраненного журнала приложение переместит файлы обратно в исходные папки и восстановит прежние имена.

Для наилучшего результата используйте отмену до начала новой сортировки в той же папке.

## 8. Обучение на основе ваших решений

Когда вы одобряете категории в окне проверки, программа запоминает эти локальные решения и использует их в качестве подсказок при будущих запусках. Это не изменяет веса самой нейросетевой модели.

Накопленные примеры хранятся в отдельной локальной базе данных, поэтому стандартная очистка кэша их не удаляет. Сбросить эти данные можно через меню **Настройки -> Сбросить обученное поведение…**.

## Полезно знать

- Приложение использует локальный кэш, чтобы не обрабатывать повторно одни и те же файлы и повышать согласованность.
- Автоподтверждение отключено по умолчанию. Включайте его только тогда, когда освоитесь с работой приложения.
- Параметры анализа изображений и документов можно раскрыть для тонкой настройки.

## Если результат выглядит неожиданным

Проверьте следующие моменты:

- выбрана именно та папка, которую вы планировали отсортировать
- включены нужные модули анализа
- режим «только переименование» не ограничивает перемещение
- белый список категорий не слишком сильно сужает варианты названий
