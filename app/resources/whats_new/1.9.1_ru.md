## Главные изменения

- Исправлены встроенные сборки среды локальной LLM для Windows: упакованные библиотеки GGML теперь работают на стандартных процессорах x64 с поддержкой SSE4.2 вместо обязательного требования AVX2.
- Исправлено развертывание встроенного набора сертификатов CA для пакетов приложения и сборок Microsoft Store: сертификаты теперь записываются в доступный для записи каталог данных приложения вместо каталога установки только для чтения.
