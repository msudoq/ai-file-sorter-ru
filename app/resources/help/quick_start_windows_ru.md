# Примечания для Windows

Панель **Проводник файлов** отображает раздел **Сетевые расположения** с подключенными сетевыми дисками, сохраненными ярлыками и недавно использованными общими ресурсами UNC.

Дополнительное расширение Проводника Windows позволяет запускать AI File Sorter прямо из контекстного меню Проводника по правому клику. Воспользуйтесь меню **Расширения -> Установить расширение Проводника Windows...**, если оно ещё не установлено.

После установки в контекстном меню Проводника появится подменю **AI File Sorter** с командами **Категоризировать**, **Переименовать** и **Категоризировать и переименовать**. В самом приложении пункт меню **Расширения -> Расширение Проводника Windows** открывает настройки расширения или окно активности.

Если вы еще не выбрали и не загрузили модель LLM, сначала откройте AI File Sorter и завершите первоначальную настройку модели перед использованием расширения.
